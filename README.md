# АРХИВ. Код наследия

Браузерная 2D-игра-расследование с видом сверху (20–25 минут). Героиня и дрон Байт путешествуют по трём «страницам» истории: Новгород XIII века, блокадный Ленинград 1941 года и Байконур 12 апреля 1961 года. Они ловят подмены, которые вносит Дублёр, а в Ядре Архива делают финальный выбор. Три концовки.

Игра сделана для ИТ-марафона «Игры во благо: код наследия».

## Как запустить

Готовая игра — файл `ИГРАТЬ.html` (его даёт `npm run build`, он лежит в `dist/index.html`). Откройте его двойным кликом, сервер и интернет не нужны.

Из исходников:

```bash
npm install
npm run dev       # режим разработки, http://localhost:5173
npm run build     # сборка в dist/index.html (один файл)
npm run check     # типы, линтер, юнит-тесты, проверка контента
npm run test:e2e  # сквозные тесты Playwright
npm run test:file # проверка запуска с file://
```

## Стек

- TypeScript (strict), Vite, vite-plugin-singlefile (весь бандл в один HTML без модулей)
- Phaser 3.90: сцены, камера, частицы, свет
- DOM-слои для интерфейса: диалоги, HUD, меню, лупа, доска улик
- Вся графика процедурная: пиксельный холст в коде, спрайты, портреты и локации нарисованы кодом
- Звук и музыка синтезируются в Web Audio (процедурные инструменты и голоса)
- Тесты: Vitest (юнит), Playwright (сквозные и проверка `file://`)
- Шрифты: Press Start 2P, PT Sans, Caveat (лицензия OFL, через @fontsource)

Внешних картинок, музыки и CDN нет. Сборка весит около 2,7 МБ.

## Структура

- `src/world` — сцены и локации, эффекты, свет
- `src/gfx/td` — процедурная графика вида сверху
- `src/core` — движок сценариев, состояние, сохранения
- `src/content` — диалоги и данные эпох
- `src/ui` — интерфейс и мини-игры
- `src/audio` — звук
- `docs/story` — исходный сценарий (нужен проверке контента)
